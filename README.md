# FileVellum

**Live Website:** [https://filevellum.onrender.com/](https://filevellum.onrender.com/)

**FileVellum** is a fast, free, all-in-one digital workspace offering **220+ browser utilities** to convert, merge, compress, organize, and edit PDFs, images, documents, archives, and developer files securely—without requiring any sign-up[cite: 3].

---

## Key Features

- **Create & Convert PDF:** Convert Word, Excel, PowerPoint, JPG, PNG, HTML, Markdown, CSV, and EPUB to PDF—and convert PDFs back to Word, Excel, PowerPoint, JPG, PNG, Text, HTML, JSON, or PDF/A[cite: 3].
- **Organize, Edit & Secure PDF:** Merge, split, reorder, rotate, crop, resize, add page numbers/watermarks, sign, redact, flatten, repair, password-protect, or unlock PDF files[cite: 3].
- **Optimize & OCR PDF:** Compress PDFs, convert to grayscale, run OCR to make scanned PDFs searchable, inspect fonts/page sizes, and extract embedded images[cite: 3].
- **Image Editing & Conversion:** Background Remover, Image Compressor, Resizer, Cropper, Passport Photo Maker, Upscaler, Color Palette Extractor, EXIF Viewer, and converters across JPG, PNG, WebP, AVIF, SVG, HEIC, and ICO[cite: 3].
- **Document & Archive Utilities:** Convert between DOCX, TXT, HTML, CSV, Excel, JSON, XML, RTF, and ODT; create, inspect, merge, password-protect, and extract ZIP, TAR, and TAR.GZ archives[cite: 3].
- **QR, Barcode, Text & Developer Tools:** QR Code & Barcode generators/scanners, Word/Character Counter, Text Diff Checker, Speech-to-Text, JSON/HTML/CSS/JS formatters & minifiers, Regex Tester, JWT Decoder, and UUID/Password generators[cite: 3].

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript, GSAP (ScrollTrigger)[cite: 3]
- **Icons & Fonts:** Font Awesome, Google Fonts (`Inter`, `Space Mono`)[cite: 3]
- **Deployment:** Render

## Run Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/yashrajsinghgujjar/FileVellum.git](https://github.com/yashrajsinghgujjar/FileVellum.git)
   cd FileVellum
   ```

2. **Install required dependencies from `requirements.txt`:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
   Open `http://127.0.0.1:5000` in your browser.
